Load a bundle

—

Drop one project JSON at a time. Each file is merged into the stored corpus. Re-uploading the same project replaces only that project.

Get the JSON from the dataset generator: github.com/ichsanbudiman/DEPICT.

One file is one project. project, hops and neighbourhood sit on the bundle, and source sits in snippets (path, line window, text). Each instance needs an id, a root name, and a graph: nodes as {id, kind, file, lines}, edges with src_id, dst_id and a relation_type array, plus root and structural_features. Node labels are derived from the ids. in_model_view: false is a node or edge the pruning rule removed: drawn dashed, and hidden when Pruned graph is checked. proposed is omitted by the server when the instance is blind.

Re-uploading a project replaces only that project. Annotations already recorded are kept and stay matched by id, so re-loading a corrected bundle does not lose work. A file that still carries project or files on each instance loads as before.
