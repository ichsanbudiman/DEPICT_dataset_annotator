Agreement by pattern

For one pattern, over every completed verdict:

S
number of verdicts given
U
number of those that were unsure
Y
number that were yes

Yes rate = Y / (S − U)

Unsure = U / S

For a pair of annotators on the same instance, counting only yes and no. An unsure answer is left out of these counts.

n11
both said yes
n10
first yes, second no
n01
first no, second yes
n00
both said no

n = n11 + n10 + n01 + n00

po = (n11 + n00) / n

pe = [(n11 + n10)(n11 + n01) + (n01 + n00)(n10 + n00)] / n2

κ = (po − pe) / (1 − pe), and κ = 1 when pe = 1

PABAK = 2 · po − 1

With more than one annotator pair, each pair is counted this way. The n cell is the sum of those n values. po and κ are the mean of the pair values. κ is amber when PABAK − κ is greater than 0.2.

Label set agreement

On one instance, a label set is the patterns an annotator marked yes.

For a pair of annotators on the same instance:

Intersection
patterns both marked yes
Union
patterns either marked yes

Jaccard = intersection / union

Jaccard, mean = the mean of Jaccard over pairs whose union is not empty

Exact set match = (pairs with the same set) / (all pairs). Both sets empty counts as the same set.

Hamming uses every pattern cell where both people answered, including no and unsure.

Hamming agreement = (cells with the same answer) / (cells both answered)

Both sets empty is the number of pairs where neither person marked a pattern yes. Those pairs are in the exact-match count and left out of the Jaccard mean.
